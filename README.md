# Koray - Rafta

Hırdavat deposu için ürün bulucu. Ürünü yazınca depo planında girişten rafa giden yolu ve rafın hangi bölme/katında olduğunu animasyonla gösterir. İnternetsiz çalışır.

## Android (APK)
1. Telefondan bu reponun **Releases → son-surum** sayfasını açın.
2. `KorayRafta.apk` dosyasına dokunup indirin.
3. Açın; "bilinmeyen kaynaklardan yükleme" izni sorulursa verin ve **Yükle**'ye basın.

## iPhone
1. Safari'de `https://mohbai-code.github.io/depo-bul/` adresini açın (ilk sefer internet gerekir).
2. **Paylaş → Ana Ekrana Ekle**.
3. Bundan sonra ana ekrandaki simgeden internetsiz açılır.

## Listeyi telefonlar arasında paylaşma
Uygulamadaki **Listeyi paylaş / içe al** bölümünden: Paylaş → WhatsApp. Karşı taraf metni kopyalayıp aynı bölüme yapıştırır ve **İçe al**'a basar.

## Güncelleme
`www/index.html` değiştiğinde GitHub otomatik olarak yeni APK ve web sürümü üretir.
